DrahtGrün rechts: abstehende Teile, z. B. «Ohren 4+1» = 4 Perlen und 1 Endperle

Zum Korrigieren rechts eine Farbe wählen, dann auf Perlen tippen oder darüber ziehen. Gleich neben das Ende einer Reihe tippen setzt dort eine Perle dazu. «Perle weg» nimmt eine Perle heraus (bei Ohren und Beinen das ganze Paar). Nochmals auf die Farbe tippen beendet das Malen.

Hintergrund

Tipp: Figuren von vorne mit klarem Umriss werden am schönsten. Beim Fädeln liegt jede Reihe mittig unter der vorherigen, darum wird die Figur gerade gerichtet. Ohren, Arme und Beine, die abstehen, kommen als Paare an eine Reihe. Was nur auf einer Seite absteht (z. B. ein Schwanz), fällt weg.
